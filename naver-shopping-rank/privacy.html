처리하는 정보와 목적

이 확장은 사용자가 수집 버튼을 누르면 입력한 검색어의 네이버 쇼핑 모바일·PC 검색 화면을 열고 상품 목록을 읽습니다. 검색어, 검색 URL, 상품명, 상품 ID·링크, 판매처, 표시가격·정상가·혜택 정보, 광고 구분·순위, 정렬·필터, 화면에 표시된 로그인 여부, 수집 시각과 실행 상태·오류 사유를 처리합니다. 이 정보는 상품 순위를 표시하고 상품·실행 로그 CSV를 내보내기 위해서만 사용합니다.

다른 사이트의 방문 기록이나 내용을 수집하지 않습니다. 계정 이름, 비밀번호, 인증 토큰, 결제 정보와 쿠키를 읽거나 저장하는 기능은 없습니다. 로그인 여부는 검색 화면에 표시된 로그인·로그아웃 문구로만 확인하며 인증정보를 읽는 것을 뜻하지 않습니다.

저장과 외부 전송

검색어 설정과 수집 결과는 사용자의 Chrome 프로필에 있는 확장 로컬 저장소에 보관합니다. Chrome 동기화 저장소를 사용하지 않습니다. CSV 내보내기를 누르면 사용자의 다운로드 폴더에 파일을 저장합니다.

검색 화면을 열기 위해 입력한 검색어는 HTTPS 검색 URL을 통해 네이버에 전달됩니다. 네이버 검색 화면의 서비스 이용과 데이터 처리는 네이버의 개인정보처리방침에 따릅니다. 확장은 수집 결과를 개발자 서버나 분석 서비스로 전송하지 않습니다.

제공·판매와 이용 제한

개발자는 확장에서 처리한 검색어와 수집 결과를 전달받거나 열람하지 않으며, 제3자에게 판매·제공하거나 개인 맞춤 광고에 사용하지 않습니다. 사용자가 직접 CSV를 공유하는 경우에는 사용자가 선택한 수신자에게 파일 내용이 전달됩니다. 이 확장의 사용자 데이터 이용은 Chrome 웹 스토어 사용자 데이터 정책과 Limited Use 요구사항을 준수합니다.

보관 기간과 삭제

이전 실행 결과는 새 실행으로 교체되거나 사용자가 결과 지우기를 누를 때까지 로컬에 보관됩니다. 중단된 실행을 다시 시작하면 같은 실행의 완료되지 않은 검색을 이어 갑니다. 결과 지우기는 상품과 로그를 지우지만 검색어는 남깁니다. 검색어를 지우려면 입력란을 비워 주세요. 확장을 제거하면 확장의 로컬 저장 데이터가 삭제됩니다. 이미 다운로드한 CSV는 별도로 파일을 삭제해야 합니다.

필요한 권한

storage는 검색어와 수집 결과의 로컬 저장, scripting과 네이버 쇼핑 PC·모바일 검색 호스트 접근은 검색 화면의 상품 목록 읽기·스크롤, downloads는 사용자가 요청한 CSV 저장에 사용합니다. debugger, cookies, history 권한을 요청하지 않습니다. 원격에서 내려받은 코드를 실행하지 않습니다.

개발자와 문의

개발자: AndyEEL. 문의는 Chrome 웹 스토어 등록정보에 표시된 개발자 연락처를 이용해 주세요. 문의 과정에서 사용자가 자발적으로 제공하는 정보는 해당 문의를 처리하는 데에만 사용합니다. 검색어·CSV 전체를 보내야만 지원을 받을 수 있는 것은 아닙니다.

방침 변경

처리 데이터나 동작이 변경되면 이 문서와 시행일을 갱신합니다. 데이터 이용 방식에 중요한 변경이 있으면 확장 안내와 스토어 등록정보에도 알립니다.

이 확장은 네이버가 제공하거나 보증하는 공식 확장이 아닙니다.
